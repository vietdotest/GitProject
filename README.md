# GitProject

Luyện tập quản lý mã nguồn với Git và GitHub.

## Cấu trúc
- `source/index.html`: trang giới thiệu dự án.
- `source/news.html`: trang tin tức, liên kết hai chiều với trang chủ.

## Quy trình
1. Tạo repository GitProject.
2. Lưu README vào một commit và đưa lên GitHub.
3. Clone repository về máy.
4. Thêm hai trang trong thư mục source, kiểm tra và tạo commit tiếp theo.
5. Push lên main và so sánh SHA cục bộ với remote.

## Ý nghĩa lệnh
`clone` sao chép cả tệp và lịch sử; `add` chọn thay đổi cho lần commit;
`commit` lưu phiên bản cục bộ; `push` gửi phiên bản lên GitHub;
`status` kiểm tra trạng thái; `log` xem lịch sử; `remote -v` kiểm tra URL đồng bộ.

## Chạy
Mở `source/index.html` trong trình duyệt hoặc dùng một máy chủ web tĩnh.
