Quản lý mã nguồn cùng Git

Dự án gồm hai trang HTML đơn giản để luyện tập tạo tệp, commit và đồng bộ mã nguồn lên GitHub.

  1. Kiểm tra thay đổi với git status.
  2. Chọn tệp với git add.
  3. Lưu phiên bản với git commit.
  4. Đồng bộ lên kho từ xa bằng git push.
